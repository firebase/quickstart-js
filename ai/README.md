# Firebase AI SDK Quickstart

This directory contains samples for the Firebase AI SDK for Web.

## Table of Contents

1. **Firebase AI Logic Feature Samples (`ai-samples/`)**: provides sample apps each demonstrating a single feature of the Firebase AI SDK for Web.

2. **Firebase AI Logic Sample App (`ai-react-app/`)**: demonstrates multiple features of the Firebase AI SDK for Web integrated into a web application built with React and TypeScript.
